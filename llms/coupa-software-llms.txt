# Coupa Software

> Coupa Software is a business spend management (BSM) platform unifying procurement, invoicing, expense management, payments, supplier management, sourcing, and contract lifecycle management. The Coupa Core API is a UTF-8 RESTful interface (XML and JSON) for creating, reading, updating, and acting on records within a Coupa instance, secured with OAuth 2.0 / OIDC.

## APIs

- [Coupa Core API](https://compass.coupa.com/en-us/products/product-documentation/integration-technical-documentation/the-coupa-core-api): Create, update, and act on individual Coupa records (purchase orders, requisitions, invoices, suppliers, users, expenses, contracts, receipts, and reference data).
